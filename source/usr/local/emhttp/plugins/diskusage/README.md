**Disk Usage Plugin**

WinDirStat-style disk usage analyzer for Unraid.

**Features:**

- Treemap of any share, disk or folder, colored by file type
- Folder tree with sizes and percentages
- Extension legend and largest-files list
- Allocated vs apparent size toggle
- Background scanner with progress - no reboot needed for results (stored on the flash drive)

Scan the merged share view with `/mnt/user`, or a single physical disk such as `/mnt/disk2`.
Scans walk the entire filesystem, so on a large HDD array expect minutes, not seconds.
